BOOK LAUNCH LANDING PAGE — PROJECT STRUCTURE
============================================

index.html        Page content and metadata
css/style.css    All page styles, including responsive layout rules
js/main.js       Interactive behavior (copy account buttons, mobile navigation, footer year)
images/          Image-assets folder; see images/README.txt

HOW TO RUN
1. Keep the folder structure intact.
2. Open index.html in a browser, or upload the complete folder contents to your web host.
3. The current images remain linked to the original external image host, because the actual image files were not supplied with the HTML. See images/README.txt to switch them to local files.

No page copy or design content was intentionally changed during this separation; the inline CSS and JavaScript were moved into external files and linked back to the HTML.
